# STYN
App web para promover la **riqueza cultural y biodiversidad de Nicaragua**, conectando turistas, guías y sitios turísticos en un solo ecosistema digital.

## 📋 Descripción del Proyecto
YULU-NICARAGUA es un proyecto académico y funcional que busca digitalizar la experiencia turística en Nicaragua.  
Permite a los usuarios:
- **Explorar** sitios turísticos y su biodiversidad a través de un mapa interactivo y contenido informativo.
- **Reservar tours y actividades** con guías turísticos aprobados.
- **Registrar guías** para ofrecer sus servicios en la plataforma.

El sistema está pensado para ser **escalable**, **seguro** y **fácil de usar**, integrando módulos transaccionales y de contenido.

## 🧩 Módulos Principales
- **Registro de Usuarios**  
  Autenticación y perfil para turistas y guías.
- **Guías Turísticos**  
  Registro y aprobación de guías.
  - **Reservas**  
  Sistema para crear y gestionar reservas con cálculo automático de precios y comisiones.
- **Sitios Turísticos**  
  Página informativa y mapa interactivo mostrando los principales destinos del país.
  - **Catalogo de Aves**  
  Catalogo de Aves endemicas y migratrias a nivel nacional.
  - **Eventos**  
    Tablero de eventos o actividades que se realizan en los diferntes departamentos del pais por fechas.
  - **Educación**  
  Modulo de educación cultural y natural acerca de Nicaragua.
  - **Reservas Naturales**  
  Fichero de las reservar naturales activas del pais, con descripcion y localidad.
- **Panel Principal (Dashboard)**  
  Interfaz moderna y responsiva con acceso a todos los módulos.

## 🖥️ Tecnologías Utilizadas
- **Back-end**: PyCharm, Django + Django REST Framework (API RESTful) + Miniconda
- **Base de Datos**:SQL Server 
- **Front-end**: VisualCode, HTML5, CSS3, JavaScript (responsivo y dinámico)
- **Mapas**: Google Maps (Mapas personalizados embebidos)
- **Correo**: SMTP (envío automático de confirmaciones de reserva)
